# ♟ Downloader de Aberturas de Xadrez

Uma aplicação em Python com interface gráfica feita em **PyQt5** para baixar partidas de uma abertura específica diretamente do **Chess.com**, usando **Selenium** para automação do navegador.

## ✨ Funcionalidades

- Interface bonita e simples com tema inspirado em xadrez
- Busca partidas por nome da abertura
- Abre o navegador automaticamente
- Seleciona todas as partidas disponíveis na página
- Faz o download das partidas com poucos cliques
- Exibe logs e status em tempo real
- Executa o processo em segundo plano para não travar a interface

## 🛠 Tecnologias utilizadas

- Python
- PyQt5
- Selenium
- webdriver-manager
